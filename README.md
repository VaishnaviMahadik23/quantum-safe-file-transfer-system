# Quantum-Safe File Transfer Application with hybrid encryption 

## Overview

A secure enterprise web application demonstrating hybrid encryption using:

- AES-256-GCM
- ML-KEM (Kyber)
- ML-DSA (Dilithium)
- SHA3-256

## Technology Stack

- React 19
- Spring Boot 3
- PostgreSQL
- Redis
